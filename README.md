## Features

- Kanban-style task board with drag-and-drop
- Team member assignment and priority levels
- Real-time data sync via Firebase

## Team & Process

Built in a team of 4. Tasks were distributed via Git branches with regular check-ins. The codebase was structured with a focus on readability and consistent naming conventions.

## What I learned

- Collaborative development with Git branching strategies
- Integrating Firebase for real-time data
- Writing structured, readable code in a team environment
